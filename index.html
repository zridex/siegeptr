MoP 5.5.4 AddOn fixes

Updated June 4, 2026 MoP 5.5.4.67969 Discord @zridex

Quick compatibility pass

These are quick compatibility fixes for SoO PTR testing and the live MoP client after PTR UI changes started landing. They were briefly tested until no relevant addon errors showed up in the current pass, but they are not full addon releases or extensively maintained builds.

Install

  1. Close the WoW client.
  2. Unzip the download.
  3. Open your World of Warcraft install folder.
  4. Copy the addon folders into the AddOns folder for the client you are testing.
  5. Enable out-of-date addons if the client asks.
